# Signing Kontrol Listesi

## Apple
- [ ] `com.knigdelioglu.olcerim` App ID oluşturuldu.
- [ ] Development certificate/provisioning doğrulandı.
- [ ] Distribution certificate/provisioning doğrulandı.
- [ ] TestFlight archive gerçek cihaz signing ile oluşturuldu.
- [ ] macOS sandbox entitlements doğrulandı.
- [ ] macOS notarization veya Mac App Store signing doğrulandı.
- [ ] Hiçbir `.p12`, `.pem`, provisioning profile repoda yok.

- [ ] Upload keystore repo dışında oluşturuldu ve yedeklendi.
- [ ] `key.properties` yalnız yerelde/CI secret'tan üretiliyor.
- [ ] Release AAB imzalı üretildi.
- [ ] Keystore veya parola repoda yok.
