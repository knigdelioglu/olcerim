# Ölçerim 1.0 — Store Screenshot Planı

Ekran görüntülerinde yalnız sentetik `Demo Öğrenci` verileri kullanılmalıdır.

## Mesaj sırası

1. **Sınıfını saniyeler içinde hazırla** — Sınıflar / öğrenci listesi
2. **Rubriğini bir kez oluştur, tekrar kullan** — Rubrik editörü
3. **Ders sırasında hızlı değerlendir** — Telefon değerlendirme oturumu
4. **Tablet ve Mac'te tüm sınıfı gör** — Gradebook
5. **Sonucu hemen anla** — Sınıf sonuçları
6. **PDF ve Excel olarak çıkar** — Rapor önizleme / paylaşım
7. **Şifreli yedeğini kendin sakla** — Backup ekranı

## Cihaz seti

- iPhone standart/büyük ekran
- iPad portrait veya landscape
- Android telefon
- Android tablet mümkünse
- macOS `1440x900` ürün penceresi

## Çekim kuralları

- Sistem durum çubuğunda kişisel bildirim yok.
- Gerçek okul/öğrenci adı yok.
- Demo verisinin sentetik olduğu QA sırasında doğrulanır.
- Light theme ana set; dark theme en fazla tamamlayıcı görsel.
- Ana CTA ve ürün işlevi ilk viewport'ta görünür.
- Store üzerine sonradan eklenen başlık metinleri UI öğelerini kapatmaz.

## Üretim durumu

Gerçek screenshot dosyaları Faz 14 build doğrulaması ve gerçek simulator/device capture sonrasında üretilmelidir. Mock screenshot store kanıtı olarak kullanılmaz.
